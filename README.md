# GDBR — Game Database & Reviews

A Django-based PC game database and review platform.

## Live Demo
https://gdbr-1.onrender.com

## Features
- Game search with IGDB
- User accounts and email verification
- Game libraries
- Comments and profiles
- GDBR AI Assistant
- Cloudinary media storage
- PostgreSQL database on Neon

## Tech Stack
- Django
- PostgreSQL
- Neon
- Render
- Cloudinary
- Brevo
- OpenAI API
- IGDB API
